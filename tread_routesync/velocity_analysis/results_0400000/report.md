# RouteSync 400K sparse velocity 분석

**결론: 이 체크포인트의 최종 velocity에서 R–P 쌍이 R–R/P–P보다 일관되게 더 불일치한다는 뚜렷한 증거는 확인되지 않았다.** 경계 전용 loss를 우선 추가할 근거는 현재 결과로 부족하다. 이는 중간 hidden representation에 문제가 없다는 뜻이나, RouteSync가 그 문제를 해결했다는 인과적 증거는 아니다.

## 설정

- 체크포인트: `/v/mnt/GH/SiT/tread-routesync-b/checkpoints/0400000.pt`
- EMA, SiT-B/2, 400,000 step, ImageNet 256, routed interval `[3,9)`, active ratio 0.5, recursive OFF, RouteSync weight 0.1. 저장 시 post gradient 설정이 없으므로 기존 stop-gradient 학습 설정.
- Sparse eval만 사용. 추가 dense forward 없음. CFG=1, BF16 inference; 통계는 FP32 계산.
- Noised data: 학습 데이터에서 무작위 256개 latent, 7개 t, 이미지마다 routing mask 2개. 같은 이미지/latent/noise/mask를 t별로 재사용.
- 생성 경로: 별도 32개 noise-to-latent Euler ODE, 50 step, 경로마다 고정된 random routing, 6개 위치 분석. VAE decode/FID 평가 없음.
- `t=0`: clean, `t=1`: noise.

## Random routing에서도 인접 비교가 가능한 이유

Random인 것은 각 위치의 R/P 역할이다. 원래 위치 index는 그대로 보존되므로 16×16 token grid의 상하좌우 인접 쌍을 만든 다음 R–P/R–R/P–P로 나눌 수 있다. 한 forward의 전체 쌍은 R–R 8,128개, R–P 16,384개, P–P 8,128개다. Self-pair와 역순 중복은 제외했다.

인접 patch는 2×2×4=16차원 velocity vector끼리 비교한다. 실제 경계 pixel 분석은 서로 닿는 latent pixel의 4차원 vector를 비교한다. 두 정의를 별도로 제공한다.

## Noise level별 R–P 추가 차이

기준은 이미지별 `(R–R + P–P)/2`. 표의 상대 차이는 `100 × (R–P − 기준)/기준`이며, 신뢰구간은 절대 차이 단위다. Routing 반복을 이미지 안에서 평균한 뒤 이미지 단위 2,000회 paired bootstrap을 사용했다. 쌍 수를 독립 표본 수로 사용하지 않았다.

전체 쌍의 v L1 차이는 최대 약 0.015% 수준이고, 모든 t에서 차이의 신뢰구간에 0이 포함된다. 인접 patch의 R–P v L1은 같은 그룹 평균보다 오히려 약 0.01–0.14% 낮지만 모든 신뢰구간에 0이 포함된다. 실제 경계 pixel의 FM target 잔차 차이는 약 −0.19%에서 +0.23%이며 모든 신뢰구간에 0이 포함된다.

`error`는 `e = v_pred - (eps - x0)`이고, 위 오차차 L1은 `mean(abs(e_i-e_j))`다. 이 값은 noise/clean sample로 만든 conditional FM target에 대한 잔차이며, true marginal velocity 오차 자체는 아니다. 원래 target의 pair similarity/L1도 CSV와 대시보드에 함께 제공한다.

## 해석과 후속 실험 우선순위

1. 현재 최종 출력만 보면 R–P 경계 문제가 큰 병목이라는 주장은 지지되지 않는다. 앞서 제안한 경계 loss는 우선순위를 낮추는 것이 타당하다.
2. 최종 suffix가 중간 차이를 이미 교정했을 수 있다. Routed layer 자체를 개선하려는 목적이라면 이후에는 routed 출구와 첫 suffix 전후의 hidden-state 관계 변화를 분석하는 편이 더 직접적이다.
3. RouteSync 없는 TREAD checkpoint를 측정하지 않았으므로, 현재 차이가 작은 이유가 RouteSync 효과인지 기존 TREAD/suffix 효과인지는 구분할 수 없다.
4. 현재 수치는 학습 데이터의 무작위 subset에서 얻은 진단이다. 모델의 held-out 성능, FID, perceptual 품질을 의미하지 않는다.
5. 여러 비교에 대한 보정 없는 95% pointwise CI다. 통계적으로 구분되는 소수 값만 골라 새로운 loss의 근거로 삼지 않는다. 전체 쌍 평균은 국소적·소수 token의 실패를 희석할 수도 있다.
